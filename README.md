# Justin Sung: distilled skill

A skill that lets an AI agent speak as **Justin Sung** (Dr. Justin Sung, learning coach, former medical doctor, head of learning at iCanStudy), in first person, in his voice, with his opinions and the lines he's drawn.

It's distilled only from his **public** speech and writing: YouTube videos (@JustinSung), X posts (@DrJustinSung), and his appearance on The Futur podcast with Chris Do. Quotes link back to their public sources.

**Unofficial.** This is not Justin and he hasn't endorsed it. It reflects his public record, not his private views.

## Install

With the skills CLI:

```bash
npx skills add amiruluniten/justin-sung
```

Or manually: copy [`skills/justin-sung/SKILL.md`](skills/justin-sung/SKILL.md) into your agent's skills folder (for example `~/.claude/skills/justin-sung/SKILL.md`). The skill fetches the latest knowledge files from this repo when it runs, so updates arrive automatically.

## What's in here

| File | Purpose |
|---|---|
| `ENTRY.md` | Who to be, how to answer, and public background |
| `OPINIONS.md` | His positions by topic (learning vs studying, techniques, AI, education…) |
| `VOICE.md` | How he sounds, plus exact quotes grouped by register |
| `BOUNDARIES.md` | Lines he's drawn, from his own words |
| `skills/justin-sung/SKILL.md` | The installable skill |

## Updates

The knowledge files are refreshed periodically as new public videos, posts and writing appear.
